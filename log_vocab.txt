# frac2csv log vocabulary: what the names on well logs mean.
#
# One list for every reader of well logs: the WellSight log files now, PDF
# printouts next. Each line names a thing by its key, then the spellings that
# mean it:
#
#     key | Name | extra = spelling, spelling, ...
#
# "| Name" and "| extra" may be left out; what extra means is said at the top
# of each section. A line that starts with spaces carries on the line above.
# Case, spaces and punctuation are ignored when a name is looked up (units
# keep their punctuation). A spelling with a comma in it goes in double quotes.
# Lines starting with # are notes.
#
# A spelling may mean only one thing in a section. Check the file with
#     python3 -m unittest tests.test_log_vocab
# and list the spellings a folder of converted logs uses that are not here yet
# with
#     python3 -I validation-tools/log_vocab_harvest.py FOLDER
#
# Names only: never a well's name, location or licence, nor a person's name.
# The repository is public.

# carries its own symbol library, so one thing has many codes; these are the
# codes the 8,954 logs of the WellSight drive use. A printout's legend prints
# the same codes beside each pattern.
