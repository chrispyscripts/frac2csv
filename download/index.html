Frac2CSV
frac report PDFs → per-second CSV / Excel · desktop app

Windows

One file, no install. Runs the same interface as Carmine's Lab, entirely on your machine — files never leave it.

Download Frac2CSV.exe Release notes
  • Double-click Frac2CSV.exe — a console window opens (that's the engine) and the app opens in your browser.
  • Drop PDFs or a .txt drive list. List paths like K:\BCER-Frac\… resolve automatically on whatever drive letter holds the files; exports save beside each PDF.
  • Handles scanned/raster charts (STEP, Halliburton treatment plots) — the OCR engine is bundled.
  • Close the console window to quit.

Windows SmartScreen may warn on first run (the app is unsigned): click More info → Run anyway.

Web version

Same interface in the browser — vector charts and report tables, no install. Scanned documents need the desktop app.
