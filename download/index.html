v1.0.0

  • Trican POST-FRAC SUMMARY reports now carry a date and a start time. They previously exported neither — 0 of 39 stages on 00005, 0 of 28 on 00317 — because the chart only prints elapsed minutes. Both are now read off the STAGE INFORMATION page that follows each chart. Across all 192 Trican files, 6,657 of 6,795 stages (98%) are dated, and the derived clock runs forwards on every one of them
  • Schlumberger fluid and proppant breakdowns are exported. Each Zone and Interval Summary sheet prints a per-stage fluid table (pad, slurry, spacer, flush, sweep — or the PUMPDOWN/FRAC steps) and a per-proppant-type table with designed vs placed tonnage. Neither was read before; 4,514 fluid rows and 1,805 proppant rows across 513 sheets in testing
  • Six Liberty 2025 files that produced nothing now extract in full. Their curves are drawn as filled ribbons rather than stroked lines, which the reader skipped entirely, and two of them title their charts "STG 1" instead of "Stage 1" so were never even detected. 01103, 01104, 01105, 01106, 01397 and 01398 now give 568 of 568 chart pages and 1.94 million samples, from zero
  • Correction to values in earlier builds — please re-export affected Liberty wells. A black curve with its own printed axis was being read off a coloured axis of the same unit. Where the two disagreed the numbers were wrong, not just imprecise. Across all 12 Liberty vector files, 403 of 901 pages carried a wrong value, and every one of them is a black series — no coloured channel moved anywhere. Hydr Pressure came out roughly 4.5x too high on 182 pages, pinned near the top of the chart. PFR-ZC FR CONC came out too LOW by a factor that depends on the range printed on that page: half on 147 pages, a third on 73, a quarter on 1. Do not try to correct an old export by multiplying — the factor is not the same on every page. Re-export the affected wells. Verified against the reports' own printed axes and the ink position on the page
  • Choose which columns your CSVs carry. A new Columns… button in the Export menu lists every column for the file on screen with a checkbox each. Save as default for this filetype remembers it per service provider, so unchecking a column once on a Liberty file applies to every Liberty export after it. UWI, STAGE and DATETIME always export, so a row can always be traced back
  • The export destination folder is now actually used. Setting a destination did nothing whenever the PDF's own folder was writable — the export reported success and the folder you chose stayed empty. The export panel now also names the folder the files really went to
  • A batch of files with no data files ONE report, not one each. "Report all empty" sends a single report listing every file and its reason
  • Flagging an error survives a GitHub outage. A 503 is retried, and if it still fails the message says the service is down and your report is still there to re-send — it is no longer discarded-looking
  • The app keeps a log. Errors used to go to a console window and nowhere else. There is now a log file (its location is printed when the app starts) with the full detail of any failure, which you can send with a report

v0.9.10

  • Trican concentration: the stretches where conc sits at zero — the pad at the start of a stage and the flush at the end — were coming out blank. The chart draws that line on the frame and the frame was painted over it. DH Prop Conc goes from 29% blank to 2%; WH Prop Conc from 51% to 41% and is improved but not finished
  • CalFrac dates: a well prints its Multiple-Zone summary as a run of sheets carrying different days, and a chart was taking the last of them. Against BCER's filed dates, stages dated exactly right go from 58% to 72% across 242 wells
  • CalFrac stages that would not separate now split, using the printed zone start times to pick the real boundaries out of the pumping data
  • The Stacked window stays in step with the Lab — it recovers on its own after the Lab is reloaded, and a push that fails to land is re-sent instead of leaving one chart's numbers under another chart's page number
  • Full page view no longer drops the ghost overlay from the top graph — the two are separate pictures now
  • Schlumberger Zone Summary sheets carry their chart geometry, so the IMAGE tag shows and Compare Original frames the chart instead of fitting the whole sheet
