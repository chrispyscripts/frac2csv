**Trican 1: no more small spikes where the pressure climbs or falls.** These were never on the chart. Trican 1's charts are pictures, and each curve is read one column of pixels at a time. Where the pressure moves steeply, a column holds a tall run of the curve's ink, and the reader takes the end of that run furthest from the trend, so a real pressure peak keeps its full height instead of being averaged down. On a steady climb every column is like that, and the end it took flipped between top and bottom from one column to the next. 47477 stage 43's pressure, a straight climb from about 1 to 26 MPa, came out as 1.7, 4.5, 10.2, 7.9, 3.0, 11.1, 21.3, 18.6, 13.0. It now reads 1.1, 2.5, 3.9, 5.4, 6.7 … 25.7, as drawn.

**The reader now takes the end of a run only where the curve actually turns:** the top when it stands above the line on both sides, which is a peak, and the bottom when it stands below, which is a trough. Everywhere else it takes the middle of the run, which on a climb is the curve. Checked on every Trican 1 chart page of three filings, 251 pages, against the maxima each page prints for itself:

| | before | now |
| --- | --- | --- |
| pressure max within 1% of printed | 152 | 151 |
| pressure max within 2% of printed | 200 | 201 |
| rate max within 1% of printed | 247 | 248 |
| concentration max within 1% of printed | 236 | 236 |
| pressure samples more than 1.5 MPa off their neighbours | 1,001 | 374 |

So the peaks keep their height, and nearly two thirds of the off-trend samples go. Some of what remains is real, sharp pressure movement. For anything else there is the new filter setting below. Trican 2's charts, and every other template, read exactly as before.

**A third filter setting: "only where it jumps".** You asked for an if/else: filter only where the trace jumps by a set amount. Tick "only where it jumps" beside the filters, and the curve keeps every sample exactly as read, taking the filtered value only where the raw trace jumps away from the filtered line by more than the slider's amount. The amount is a share of each curve's own axis, from 1% to 50%, default 10%, so one setting means the same on a 0–8 m³/min rate as on a 0–1200 kg/m³ concentration. The spikes go, and the fine detail stays where no filter was needed.

- **A spike is removed whole,** shoulders and all, not just its tip.
- **A real step is left alone.** A spike jumps away and comes back, while a pump shutdown jumps and stays, so a stretch is only filtered when the trace on both sides of it sits at the same level.
- **You can see where it acted.** Every filtered stretch gets an amber band on the graph, with a tick along the top edge so a short one is easy to find at any zoom. The original trace it replaced is drawn dashed over it, so you can judge what was removed. The readout beside the slider says the threshold and how much of the trace it changed.
- **It saves like the filters do:** for one chart, for the whole well, or as a provider default. The export carries it. Settings saved before this release have no gate and read exactly as they did.

**Which templates this release touches:** the **Trican 1** chart reader (Trican's 2024–25 "Stage # N" charts), and the Lab. Every other template reads exactly as it did under v1.11.35.
