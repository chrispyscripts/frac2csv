**"1 stage starts before the stage before it finished — ?" is gone.**

That warning was about the continuous chart — the whole job re-plotted end to end, with no stage number. It opens before the first stage and closes after the last one *by construction*, so it will always look like a clock running backwards. There was never anything wrong with the printed time, and nothing to fix with "Fix time": it is not a stage.

The clock check now skips continuous charts outright, so the warning stays away even if you bring the chart back with Show.

**The file row also said "29 stages" over a list of 28.** That count was what the reader returned, before the continuous chart is held back — a row saying 29 above a list of 28 reads as a stage having gone missing. It now counts what the list actually holds.
