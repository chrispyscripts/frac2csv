**Save LAS writes one LAS file, the curve track only; and a LAS viewer in a window of its own.**

**Save LAS: one file**
- **Save LAS** now writes a single LAS file named after the log (`0229--LOG.slg` saves as `0229--LOG.las`). It holds the curve-track curves only. The CSV, JSON and printout PDF files it used to write beside it are gone.
- The file uses the finest depth step any of the log's curves is recorded at, so no reading is dropped. Before, the curve-track file was always on 0.2 m, which kept only every other reading of a curve recorded every 0.1 m. Curves recorded more coarsely repeat their nearest reading, with no averaging or interpolation.
- A log read from its printout PDF alone saves as `<name>.from-printout.las`, so it never overwrites the log's own LAS in the same folder.

**LAS viewer**
- A **LAS viewer ↗** button in the top bar opens a LAS viewer in a window of its own.
- Open or drop one or more `.las` files on it, plus a printout PDF to show beside them. For each file it shows:
  - the curves plotted by depth, with a choice of scale and Prev / Next through the open files;
  - the LAS header, a set of checks on the file, and the file's text as written.
- This is the LAS viewer from wellsight-convert, reading the files you give it.
