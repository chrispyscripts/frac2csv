**The 1,191 Alberta filings spudded 2019–2023 read.** 1,163 of them produce treatment charts; the 28 that do not each say why (nine SLB books that print only the whole job, fourteen Trican and CalFrac filings with no chart in them, three Trican reports whose charts are pasted screenshots, and two single files). Nothing errors out.

**BJ JobMaster charts read, in every form the pass found.** Titles written as "Well 3 Zone 12", "Zone #12", "Well 3 - Stage 12", "Int 12" and Husky's "Frac #12" with a qualifier; a lower-case meridian; a two-digit township; a well prefix with a letter in it. Pages set in a font with no character map are read by OCR, all of a page's labels in one pass (fifteen seconds a page down to a few); a font whose every code is shifted by 29 is put back; a chart drawn sideways in an upright page is turned; a curve drawn as hundreds of one-point paths is joined; colours that differ by a rounding error are the same pen. The year comes from whichever date spelling the book uses, and the UWI from the title when the header has none.

**STEP's 2019 books, tiled four charts to a page, read as four stages.** The clock axis of each tile is read column by column, a chart that starts before midnight keeps its day, a tile printed twice is read once, and a STEP chart with no stage number takes it from the summary's Top Depth. Vesta's vector STEP pages ("Treatment N") read too. The 2018 STEP summary reads, and a summary whose date column was split across pages is one column again.

**Scanned CalFrac overview pages read.** Pressure, rate and concentration ladders are read off the page image, the elapsed-time axis from its labels, and the curves by hue, with teal and maroon pens tried where a book uses them. A TAQA page cut off at "Time (min)" is found from its rate legend.

**Trican reports that are photocopies read.** The chart frames are found on the page image and each chart is read from its own crop. A Trican chart also clocks itself from inside its sheet's own envelope (#648), and the reader's notes travel with the stage.

**SLB zone sheets filed as strips are composited and read.**

**BJ's 2019 Totals read.** An "Interval #" heading spilt over two lines is still the interval column, and the Additives page is set aside with a note. A stage's depth is joined from a table whose heading is spilt the same way.

**Two Flag Error reports.** A Liberty re-frac stage with a lower-case letter in its label keeps the letter (#649), and Liberty's "Proppant Conc" is the wellhead concentration (#650).

**A picture the PDF library cannot decode is skipped, not fatal.**

**Export names can carry the service provider and how the charts were read.** Every Export button first asks, in a pop-up with two boxes: append the provider ("-CalFrac"), and append "-image" or "-vector". The answer is remembered.

**The Lab remembers what it has read.** Every file's results are kept on your machine (the newest ~2 GB), so a list dropped a second time comes straight back ("reused earlier analysis") and the Export button works from it. A changed file, or a new build of the reader, is read afresh; Settings → Earlier analyses → Re-read every file forces it.

**A batch export shows its progress and finishes what it can.** Each file's row says when it has been saved and where, every CSV is written before any Excel file is started, a file that fails is listed at the end and the rest still go, and a failure carries the server's own reason. On a drive the system will not write to, the files land in Downloads and the row says so.
