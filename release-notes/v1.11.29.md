**Ten more units of reach on every filter.** The far end of the slider was not enough on the worst traces, so each filter's ceiling goes up by ten of whatever unit it reports beside the slider: Hampel and the plain median now run 3 to **41** samples, Savitzky-Golay 5 to **51**, and LOESS spans 2% to **30%** of the stage. The bottom of the slider is untouched — 0 still means off, and the first notch is still the gentlest setting there was.

**What that costs, said plainly.** The slider is still 0 to 100, so a longer range over the same travel puts every setting lower on it. The two-step workflow's 11-21 Savitzky-Golay window used to sit at 17-44% and now sits at **13-35%**. Nothing reinterprets a setting you already saved — the stored number is the slider position and it still means that position — but a provider default dialled in on v1.11.28 will now work somewhat harder than it did, so it is worth opening one chart under it and checking you still like it.

**This is why the label counts samples.** The number beside the slider has always reported the window in samples rather than only the percentage, and that is the number worth writing down and repeating: it survives a change like this one, and the percentage does not.

**Which templates this release touches:** the Lab only. No reader changed, so any filing reads exactly as it did under v1.11.28.
