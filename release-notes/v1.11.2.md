**Every file is read fresh.** The Lab used to keep what it had already read and hand it straight back, with the row saying "reused earlier analysis", and Settings carried a toggle to turn that off. The toggle is gone and the reuse with it: drop a file and it is read by the build you are running, every time. While the readers are changing under active testing that is the only safe behaviour — a reused result is yesterday's build answering for today's, and the one chart where that matters is the one nobody thinks to re-check. Anyone who had the toggle set to Reuse has that setting cleared on first load rather than left to say something the app no longer honours.
