**You can now see which minutes of a stage came off the continuous chart.**

v1.11.7 gave Trican stage 1 back the minutes its own page does not plot — on the file we have been comparing, that is the first 194 minutes of a 296.8 minute stage, and they are printed nowhere except the job-length CONTINUOUS page at the back.

They were real stage data and they were missing, so taking them was right. But they are not the same kind of data as the rest of the stage: the continuous page draws the whole job in the width a stage page gives one stage, so a pixel there is about a minute instead of a second. Until now the chart showed them exactly like ink read off the stage's own page, and only a line in the warnings said otherwise.

The borrowed span now sits on a shaded band, and the legend above the chart names it — the number of minutes and the page they came from. The Flag Error report carries it too. On 00218 stage 1 the band runs from 20:32 to 23:46, and inside it you can see the breakdown and the pad work that used to be thrown away entirely.

Nothing changed about the data or the CSV. This is about being able to tell, at a glance, which part of a chart was read off that stage's own page and which part was borrowed.
