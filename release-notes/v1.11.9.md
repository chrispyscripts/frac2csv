**A file that is nothing but pictures now tells you what it is.**

Three of the files in your "no extractable data" batch — 00426, 00428 and 00429 — are 124-page runs of *Daily Initial Completions Report* sheets. Well shut in, no operations, no treatment chart anywhere in them. Every page is a scan, so there is no text to read and nothing to extract.

What you got back was two guesses at once: that it might need OCR, and that it might be a daily report. There was nothing to do with that but send the file again. The app now reads the banner off the page — it carries its own OCR — and answers:

> No extractable charts or tables found in 124 pages — every page is a picture, and read by OCR its pages are headed "Daily Initial Completions Report - 2020-09-30 - Day #28". This is a daily operations report, not a treatment chart, so there is nothing here to extract. If this well should have charts, they are in another file.

It reads four pages spread through the file rather than just the first, because a filing opens on a cover sheet: 00426's cover says "COMPLETION / WORKOVER" while the pages inside say what they actually are.

This only runs on a file that was going to report nothing anyway, and it adds about ten seconds to that answer.
