**Stacked view: filters now apply after the Lab window is reloaded. Every window filter now reaches 101 samples.**

**Filters in the stacked view stopped applying after a Lab reload.** The Lab and the stacked window number every message they send, so that a stale message can be recognised. A reloaded Lab starts counting from 0 again. A stacked window left open still remembered the higher number it had seen before the reload, so it treated everything from the reloaded Lab as out of date. The Lab in turn ignored the stacked window's filter changes, which carried the old number. The result was a stacked view whose filter controls changed nothing.

Reproduced with a real stacked window: after stepping through 20 stages and reloading the Lab, a filter set in the stacked view never reached the Lab. It is fixed in three ways:

- Each load of the Lab now has its own id. A stacked window takes up a newly loaded Lab at once.
- A filter change is matched to the chart it was made on. If the stacked window is showing a different chart from the Lab, the Lab sends its own chart instead of ignoring the change.
- The stacked window answers whichever Lab window last sent it a chart.

**Filter windows go up to 101 samples.** Hampel and Median used to stop at 41 samples, and Savitzky-Golay at 51. All three now reach 101; a centred window has a middle sample, so it is always odd. Robust LOESS is unchanged.

Settings saved before this release are rescaled once, so each keeps the window it was saved with. For example, a chart saved at Hampel 35% (17 samples) now reads 14% and is still 17 samples. A filter newly picked from the menu also opens where it did before, at 17 to 19 samples.

**Which templates this release touches:** none. Every template reads exactly as it did under v1.11.45. Only the Lab's filters and its stacked window change.
