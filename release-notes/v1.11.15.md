Same fix as v1.11.14, with the clock check made self-contained so the test that exercises it in isolation passes again. No change to what the app does.

**From v1.11.14:** "1 stage starts before the stage before it finished — ?" is gone. That warning was about the continuous chart — the whole job re-plotted end to end, with no stage number. It opens before the first stage and closes after the last one *by construction*, so it will always look like a clock running backwards. There was never a printed time to correct, and "Fix time" had nothing to act on.

The check now skips continuous charts outright, so the warning stays away even if you bring the chart back with Show.

The file row also said "29 stages" over a list of 28, because it counted what the reader returned rather than what the list holds. It now counts the list.
