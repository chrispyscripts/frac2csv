**Canyon: the 2017 Painted Pony and UGRBC sheets now read (#771, #772, #773).** These did not stop working in a new version. They never worked: 00203 failed the same way on every build from 1.5.0 on, and all eleven files in your reports were already on the "Canyon, not reading" list from August. Canyon drew these sheets' legend differently. The coloured sample beside each name is a filled box instead of a short line, and the legend sits just above the panel title instead of on it. The reader found the panels and both axes, could not tell which colour was which curve, and gave up on every page.

**Across the 97 Canyon files on the BC drive, 434 chart pages that failed now read, and 19 files that gave nothing now give charts.** Every chart page reads on all eleven of yours: 00203 35 of 35, 00213 24, 00301 25, 00302 18, 00303 23, 00313 21, 00314 22, 00322 20, 00344 27, 00345 23, 00352 17. **The 1,716 Canyon pages that already read come out exactly as before**, compared curve by curve.

**Two faults these sheets exposed are fixed with them.** The black curves (Bottom Hole, Combined WH, Proppant Blender) were picking up the axis tick marks and the frame's corners: 00203 stage 1's Bottom Hole read 0 to 81 MPa where the chart draws 36 to 69. And one 00301 stage prints its times in pairs, "13:15 13:30" as one piece of text, which left it with no clock. It now reads 13:00 to 17:20.

**Still not reading: the older Canyon layout** with the legend block across the top of the page ("Main Pressure", "Blender 1 Dirty Rate"). That is 188 pages on 5 files and needs a reader of its own.

**BJ: the nine "no extractable data" files in #774 now read, 415 charts where there were none.** They are BJ charts for Ovintiv, the 2025 Tower Lake pad (01247 to 01254) and Swan Lake (00730). They were flattened before filing: every letter on the chart pages is drawn as a shape, so the pages carry no text at all. The labels are now rebuilt from those shapes and read by text recognition: the clock, the stage title, the axis numbers. Only a page with no text at all and a slanted row of clock labels takes this route. Every other page reads exactly as before, checked chart by chart on 11 files that already worked, BJ, Liberty, SLB and Halliburton.

**Liberty: the per-stage summary sheets now come out as tables (#767).** WELLBORE SUMMARY, the PRESSURE SUMMARY grid, the PROPPANT SUMMARY grid and FLUID SUMMARY, volumes by stage. Each is read from the text page, not the picture page, one row per stage. Checked against the printed pages on 26 Liberty filings: every table on the 19 that print these sheets as text matches the page. On all 17 proppant grids, the printed Grand Total equals the sum of the rows. A sheet printed twice is read once. A total row goes under the column it is the total of. The flush volume keeps its own unit, whether (m3), (bbl) or (Gal). Liberty charts are unchanged. These tables are the data the summary dropdown will be built on. The dropdown itself comes next.

**The build now pins its libraries.** Every Windows build had been taking whatever version of its PDF library was newest that day. This one is built with exactly the versions v1.11.33 was, now pinned, so two builds of the same code always read a file the same way.

**Which templates this release touches:** the **Canyon** and **BJ** chart readers, and the **Liberty** summary tables. Every other template reads exactly as it did under v1.11.33.
