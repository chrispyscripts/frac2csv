**WellSight logs: rock types, accessories, other symbols and the geologist's written descriptions, read and added up.** Each log's data is listed in the middle column under headings, one entry per category, and opens faster.

**The middle column, by category**
- **Curves:** Curve Track. **Rock Types:** Rock column. **Accessories:** Mineral, Fossil, Stringer, Texture. **Other Symbols:** Oil shows, Porosity type, Sorting, Rounding, Cores & tests, Reservoir quality, Events, Slide / rotate. **Descriptions:** Samples, Shows in text, Formation tops, Events. Only the categories a log has are listed.
- Each category draws its own rows on the same depth axis and zoom as the curves, with the printed curve chart under them and its tables below. **All** puts a family's categories together.

**Rock types, accessories and other symbols**
- Every log carries its own symbol library, so the same thing is spelt many ways ("INTER", "INTERGRANULAR", "intergran./xl"; oil shows filed under three category names). Frac2CSV reads them into one vocabulary: 99.96% of the 4.77 million symbols on the WellSight drive's 8,954 logs map to a standard term. A code it does not know keeps its own name.
- **Rock column:** each rock's thickness and share, and how every curve reads in it (mean, 10th to 90th percentile).
- **Accessories:** a lane per term, with counts, density and the codes the file used.
- **Oil shows:** show symbols that run on are grouped into **show zones**, each with its strength, stain, fluorescence and cut, rock, porosity, sorting and rounding, gas against the log's background, and what the written description says across it. The three highest-scoring zones are marked; click a zone to go to it.

**The written descriptions**
- Each note in the description column is sorted into a sample description, a formation top, an event, a mud report or the header.
- A sample description gives its depth range; each rock and its share, colour, grain size, sorting and rounding, carbonate texture and accessories; porosity (types, a grade from tight to very good, the per cent quoted); and the show (stain, fluorescence, cut, odour, free oil), graded trace to strong like the show symbols, or an explicit "no show".
- Hovering over a sample shows what was read from it and the description itself.

**Faster**
- A log is decoded once instead of three times. On 400 logs, the median log opens in 0.38 s instead of 0.82 s, the slowest in 8 s instead of 22 s.

**Save LAS** now also writes `rock-types`, `symbols`, `symbol-intervals`, `show-zones`, `descriptions` and `formation-tops` CSVs and an `analysis.json`.
